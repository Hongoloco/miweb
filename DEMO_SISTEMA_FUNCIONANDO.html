⚠️ Necesitas Node.js para ejecutar el servidor

El sistema está completo pero necesitas Node.js instalado:

  1. Descargar Node.js: Ve a https://nodejs.org
  2. Instalar: Ejecuta el instalador descargado
  3. Verificar: Abre PowerShell y ejecuta node --version
  4. Instalar dependencias: En la carpeta del proyecto ejecuta npm install
  5. Iniciar servidor: Ejecuta npm start
  6. Acceder: Ve a http://localhost:3000

🎯 Una vez instalado Node.js:

El sistema iniciará automáticamente en http://localhost:3000 y podrás:

  • ✅ Hacer login con las credenciales mostradas arriba
  • ✅ Gestionar OLTs ZTE C600
  • ✅ Ejecutar comandos especializados
