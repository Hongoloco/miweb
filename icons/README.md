Los íconos para la PWA deben ser generados en los siguientes tamaños:
- 72x72px
- 96x96px
- 128x128px
- 144x144px
- 152x152px
- 192x192px

Por ahora se usan íconos placeholder. En producción, generar íconos personalizados con el logo de Antel.

Formato recomendado: PNG con fondo transparente
