🎯 Desarrollo de Servicios Residenciales

Plataforma integral para la gestión técnica de servicios de telecomunicaciones residenciales. Centraliza las herramientas esenciales para el mantenimiento y configuración de equipos OLT (ZTE C600), sistemas ACS (Auto Configuration Server) para ONTs, y gestión de abonados IMS. Diseñada para optimizar los procesos de soporte técnico, configuración de equipos y resolución de incidencias en servicios de fibra óptica, telefonía IP y acceso inalámbrico fijo (FWA).

Los comandos ACS se gestionan específicamente para cada modelo ONT que agregue. Cada modelo tendrá sus propios comandos personalizados según su fabricante y tecnología.

💡 Gestión de Comandos por Modelo ONT

  • Cada modelo ONT que agregue puede tener sus comandos específicos
  • Los comandos se almacenan junto con cada modelo individual
  • Puede copiar comandos específicos o todos los comandos de un modelo
  • Para 🔥 FWA 5G: agregue comandos de interfaz celular específicos
  • Para 🌐 GPON/EPON: agregue comandos de fibra óptica específicos
  • Marcas compatibles: ZTE, Huawei, Tozed, Nokia y otros

📋 Información Técnica ACS

  • ACS: Auto Configuration Server para gestión remota de ONTs
  • TR-069: Protocolo técnico utilizado para gestión de dispositivos CPE
  • GetParameterValues: Comando para obtener valores de parámetros
  • SetParameterValues: Comando para establecer valores de parámetros
  • AddObject/DeleteObject: Comandos para crear/eliminar objetos
  • Reboot/FactoryReset: Comandos de reinicio y reset
  • 🔥 FWA 5G: Fixed Wireless Access con tecnología 5G para acceso inalámbrico fijo
  • 📶 FWA 4G: Fixed Wireless Access con tecnología 4G LTE
  • PLMNID: Public Land Mobile Network Identifier (ID de operador)
  • Cellular Interface: Parámetros específicos para conectividad celular
  • Producción: Sistema en vivo para clientes
  • Stage/Maqueta: Ambientes de testing y desarrollo

❓ Ayuda y Documentación v2.0

🎯 Novedades de la versión con BD:

  • Base de datos SQLite: Persistencia de datos local
  • API REST: Comunicación con el servidor backend
  • Logs de actividad: Registro de todas las acciones
  • Búsqueda en BD: Búsqueda rápida en todos los comandos
  • Eliminar comandos: ✨ Eliminar comandos innecesarios individualmente
  • Gestión multiusuario: Sistema de usuarios y roles

🔧 Funcionalidades:

  • OLTs persistentes: Los datos se guardan en la base de datos
  • Comandos dinámicos: Variables {shelf}, {slot}, {port}, {onuId}
  • Gestión de comandos: ✨ Agregar, copiar y eliminar comandos fácilmente
  • Búsqueda inteligente: Busca en nombres, descripciones y comandos
  • Respaldo automático: Los datos están seguros en SQLite

🚀 Instrucciones de uso:

  1. Instalar dependencias: npm install
  2. Inicializar BD: npm run init-db
  3. Iniciar servidor: npm start
  4. Acceder a: http://localhost:3000
