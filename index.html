❓ Ayuda y Documentación v2.0

🎯 Novedades de la versión con BD:

  • Base de datos SQLite: Persistencia de datos local
  • API REST: Comunicación con el servidor backend
  • Logs de actividad: Registro de todas las acciones
  • Búsqueda en BD: Búsqueda rápida en todos los comandos
  • Gestión multiusuario: Sistema de usuarios y roles

🔧 Funcionalidades:

  • OLTs persistentes: Los datos se guardan en la base de datos
  • Comandos dinámicos: Variables {shelf}, {slot}, {port}, {onuId}
  • Búsqueda inteligente: Busca en nombres, descripciones y comandos
  • Respaldo automático: Los datos están seguros en SQLite

🚀 Instrucciones de uso:

  1. Instalar dependencias: npm install
  2. Inicializar BD: npm run init-db
  3. Iniciar servidor: npm start
  4. Acceder a: http://localhost:3000
